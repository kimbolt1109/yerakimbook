# Ex Libris Yera (yerakimbook)

A personal digital bookshelf, reading notes archive, and book report journal for Yera Kim.

## Features

- **Bookshelf (`Shelf`)**: Visual book catalog, reading status, custom covers, star ratings, and finished date tracking.
- **Reading Notes (`From the margins`)**: Page-linked notes, quotes, handwritten/drawn notes, and camera/photo uploads with captioning.
- **Book Reports (`Book reports`)**: Formatted essay reviews and thoughts on finished books.
- **Local Persistence & Privacy**: Powered by browser `localStorage` and `IndexedDB`. All notes, drawings, and covers remain strictly local on the device with full JSON export and restore capabilities.
- **Responsive & Bookish Typography**: Styled with *Libre Caslon Display*, *Libre Caslon Text*, and *Gowun Batang (고운 바탕)*.

## Development & Usage

No build step required. Open `index.html` directly in any modern browser, or serve statically:

```bash
npx --yes serve .
```
